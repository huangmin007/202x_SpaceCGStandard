## SpaceCG 常用的标准代码库

- ### Builder 里面都是构建工程，生成 dll 的
- ### SharedProjects 里面都是共享代码

---
- ### SharedProjects/SpaceCG.Standard.LedDevice 
	- 共享代码

- ### Builder/SpaceCG.Standard 
	- 基于 .Net Standard 2.0 的标准代码库
	- 基础代码库，包含一些基础的工具类，以及一些基础的数据结构
	- 支持 WPF、U3D 项目使用	
	- 不使用任何第三方库，仅使用 .Net Standard 2.0 自带的库，为跨平台、跨工具使用提供支持

- ### Builder/SpaceCG.WindowsApi
	- 基于 .Net Framework 4.8 的标准代码库
	- DeviceWatcher 串口/U盘 设备 Watcher
	- SystemExtensions 系统硬件扩展功能

- ### Builder/SpaceCG.Standard.LedDevice 
	- 基于 .Net Framework 4.8 的标准代码库
	
- ### SpaceCG.Standard.WPF
	- 基于 .Net Framework 4.8 的标准代码库
	- 包含 窗体、UI等扩展
	
- ### SpaceCG.Standard.U3D 
	- 基于 .Net Framework 4.8 的标准代码库

- ### SpaceCG.Standard.Device 
	- 基于 .Net Framework 4.8 的标准代码库
